# ClaudioPunt NBA

Daily NBA betting board: model chances blended with Australian bookmaker prices, the best price for each bet, and a settled track record.

- `index.html`: the board (reads `data/*.csv`)
- `data/`: refreshed every morning (8:16am and 10:16am AEDT)

Information only, not betting advice. Gamble responsibly: National Gambling Helpline 1800 858 858.
